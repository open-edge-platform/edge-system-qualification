## Hardware

| Processors | Specifications | Storage |
|------------|----------------|---------|
| Intel® Core™ Ultra Processor (Series 1),<br>Intel® Core™ Ultra Processor (Series 2) | **Minimum System Memory**: 32 GB<br>**BIOS**: Hardware virtualization (Intel® VT-x and VT-d) enabled | **Recommended**: 512 GB |
