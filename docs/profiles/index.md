# Profiles

Intel® ESQ runs **profiles**. A profile is a list of test cases, and each test case runs a [test suite](../suites/index.md) with the parameters set in the profile.

## Profile Types

| Type | Purpose | Benefit |
|------|---------|---------|
| **[Qualification](qualification.md)** | Measure system performance against qualification metrics | Verify that the system meets the qualification requirements |
| **[Vertical](vertical.md)** | Benchmark industry-specific proxy workloads, such as retail self-checkout, smart NVR, and manufacturing defect detection | Show the system's potential for vertical use cases |
| **[Horizontal](horizontal.md)** | General system benchmarks, such as OpenVINO™ Toolkit, audio, and memory performance | Understand resource utilization and performance |
